# LiveSub TH — ซับแปล อังกฤษ → ไทย แบบเรียลไทม์บนมือถือ (ฟรี)

แอป Android ที่ดักเสียงจากวิดีโอในแอปไหนก็ได้ (YouTube, TikTok, Facebook, ไฟล์ในเครื่อง ฯลฯ)
แล้วแสดงซับภาษาไทย (+อังกฤษ) ลอยทับจอ ทำงานในเครื่องทั้งหมด **ไม่มีค่าใช้จ่าย ไม่ต้องใช้ API key**

## การทำงาน
```
เสียงจากแอปวิดีโอ ──(AudioPlaybackCapture)──> Vosk (เสียง→ข้อความอังกฤษ, ออฟไลน์)
      ──> Google ML Kit (อังกฤษ→ไทย, ออฟไลน์) ──> กล่องซับลอยทับจอ
```

## โหมด
| โหมด | ทำงานยังไง | เหมาะกับ |
|---|---|---|
| ⚡ Realtime | ขึ้นซับทันทีระหว่างพูด แล้วแก้ให้ถูกเมื่อจบประโยค | อยากตามทัน ไม่อยากรอ |
| 🎯 แม่นยำ | รอจบประโยคแล้วค่อยแปลทั้งประโยค ช้ากว่า ~1–2 วิ แต่อ่านรู้เรื่องกว่า | สารคดี บทเรียน คลิปพูดยาว |

สลับโหมดได้ 3 ที่: สวิตช์ในแอป, ปุ่ม ⚡ บนกล่องซับ (แตะซับเพื่อเรียกปุ่ม), หรือปุ่ม "สลับโหมด" ในแถบแจ้งเตือน

## พื้นหลังซับ
- **ใส** (ค่าเริ่มต้น): ตัวขาวขอบดำแบบซับหนัง ไม่บังภาพ
- **กึ่งใส** / **ทึบ**: อ่านง่ายขึ้นในฉากสว่าง
เปลี่ยนได้จากปุ่ม ◐ บนซับ หรือในแอป

## ฟีเจอร์เสริม (v1.1)
| ฟีเจอร์ | ใช้ยังไง |
|---|---|
| ปุ่ม Quick Settings | ปัดแถบด้านบนลง → แก้ไขปุ่ม → ลาก "LiveSub" มาไว้ แตะเดียวเริ่ม/หยุด |
| บันทึกซับ | เปิดในแอป (ค่าเริ่มต้นเปิด) → หยุดแปลแล้วได้ไฟล์ `.srt` + `.txt` ที่ Download/LiveSub |
| คำศัพท์กำหนดเอง | `อังกฤษ=ไทย` (แปลตามนี้) หรือ `คำไทยผิด=คำที่ถูก` (แก้ผลแปล) บรรทัดละคำ |
| โมเดลเสียงตัวใหญ่ | ดาวน์โหลดในแอป 128MB (ใช้ Wi-Fi) แม่นขึ้น กินแรมมากขึ้น |
| อ่านออกเสียงไทย | ใช้เสียงอ่าน Google ในเครื่อง (ฟรี) ไม่ถูกดักกลับเข้ามาฟังซ้ำ |
| ตำแหน่งซับแยกแนวตั้ง/แนวนอน | ลากซับ แอปจำให้เองแยกตามการหมุนจอ |
| ตัวฟังเสียง Google ในเครื่อง (v1.3) | Android 13+: ใช้ตัวเดียวกับคำบรรยายสด แม่นกว่า มีวรรคตอน แปลดีขึ้นมาก ถ้าใช้ไม่ได้สลับไป Vosk เอง |
| แปลคำหยาบตรงตัว (v1.2) | เปิดเป็นค่าเริ่มต้น: แทนคำหยาบด้วยคำไทยระดับเดียวกันก่อนแปล + ปิดตัวกรองของ Gemini ปิดได้ในแอป |
| โหมด Gemini (ฟรี มีโควตา) | ใส่ API key จาก aistudio.google.com/apikey → ประโยคที่จบแล้วจะถูกแปลใหม่ให้เป็นธรรมชาติขึ้น ถ้าโควตาเต็มจะกลับไปใช้แปลในเครื่องเอง |

## ติดตั้งบน Xiaomi / HyperOS
1. ดาวน์โหลด `LiveSub-TH.apk` แล้วกดติดตั้ง (อนุญาต "ติดตั้งแอปที่ไม่รู้จัก")
2. เปิดแอปต่อเน็ตครั้งแรก เพื่อให้โหลดโมเดลแปลไทย (~30MB ครั้งเดียว จากนั้นใช้ออฟไลน์ได้)
3. กด "เปิดสิทธิ์ 'แสดงทับแอปอื่น'" → เปิด
4. **เฉพาะ Xiaomi:** ตั้งค่าแอป → เปิด *Autostart*, ตั้งค่าแบตเตอรี่เป็น *ไม่มีข้อจำกัด*,
   ในส่วนสิทธิ์อื่น ๆ เปิด *แสดงหน้าต่างป๊อปอัปขณะทำงานในพื้นหลัง*
5. กด ▶ เริ่มแปล → อนุญาตไมโครโฟน และอนุญาตการบันทึก/แชร์หน้าจอ (ถ้ามีให้เลือก ให้เลือก **ทั้งหน้าจอ**)
6. เปิดวิดีโอ ซับจะขึ้นเอง ลากกล่องซับขึ้นลงได้

## ข้อจำกัด
- Netflix, Disney+ และแอปที่ปิดการดักเสียงไว้ จะไม่มีซับ (ข้อจำกัดของ Android)
- โมเดลเสียงเป็นรุ่นเล็ก (40MB) เพื่อให้ทันเวลาจริง จึงอาจฟังพลาดเมื่อเพลงดัง หรือสำเนียงหนัก
- ซับช้ากว่าเสียงประมาณ 0.5–1 วิ (Realtime) หรือ 1–3 วิ (แม่นยำ)

## ไฟล์สำคัญ
- `CaptureService.kt` — ดักเสียง, แปลงเสียงเป็นข้อความ, แปล, logic โหมด Realtime/แม่นยำ
- `OverlayController.kt` — กล่องซับลอย
- `MainActivity.kt` — หน้าตั้งค่า/เริ่ม-หยุด
- ค่าที่ปรับได้ (ใน `CaptureService`): `FORCE_SPLIT_WORDS`, `PARTIAL_TRANSLATE_INTERVAL_MS`, `CLEAR_AFTER_MS`
